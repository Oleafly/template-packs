Gaste menos tempo configurando a página. Encontre um ponto de partida para seu próximo
artigo, tese, currículo, palestra, pôster ou relatório e deixe tudo com a sua cara.

Esta é uma coleção de pacotes de modelos com licenças abertas que você pode usar com
seu próprio editor e compilador. Os arquivos-fonte são `.tex`, `.typ` e `.md`
comuns. O Oleafly é opcional.

para encontrá-la de novo e ajudar outra pessoa a começar a escrever.

## Novos pontos de partida

- **Markdown:** um [relatório breve de pesquisa](../../packs/markdown-starters/markdown-research-brief/),
  uma [revisão de literatura](../../packs/markdown-starters/markdown-literature-review/) e
  um [relatório técnico](../../packs/markdown-starters/markdown-technical-report/).
- **Typst:** um [relatório de análise de dados](../../packs/reports-lab/typst-data-analysis-report/)
  e um [pôster de pesquisa A3](../../packs/slides-posters/typst-research-poster/), feitos com recursos nativos do Typst.
- **LaTeX:** uma [carta de resposta aos revisores](../../packs/academic-writing/response-to-reviewers/)
  com comentários, respostas e a localização de cada alteração.

Esses seis modelos iniciais são originais, incluem prévias renderizadas e usam CC0-1.0.
Os dados e a correspondência de exemplo estão identificados para você substituí-los pelo seu próprio trabalho.

## Como usar um modelo

Escolha um modelo e mantenha a pasta dele completa. Os arquivos de apoio
podem incluir uma bibliografia, imagens, estilos ou seções adicionais do documento.
Consulte o `template.json` e, se houver, o `SOURCE.json` para ver o compilador indicado,
as dependências, as instruções do projeto original e a licença.

Para obter a coleção:

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

Abra a pasta de um modelo no seu editor. Estes comandos geram os novos modelos
iniciais a partir das respectivas pastas:

| Formato | Gerar um PDF |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

O Markdown também pode virar um documento do Word com `pandoc main.md -o main.docx`,
ou HTML com `pandoc main.md --standalone -o main.html`.
Veja o [guia do Pandoc](https://pandoc.org/MANUAL.html) para as opções de exportação e o
[tutorial do Typst](https://typst.app/docs/tutorial/) se você ainda não conhece os arquivos `.typ`.

Os modelos importados da comunidade abrangem muitas versões e estilos. Alguns exigem
um mecanismo TeX específico, fontes instaladas ou pacotes de um registro externo. Estar no
índice não significa que o modelo foi compilado com todas as cadeias de ferramentas.

## Quer escrever e ver a prévia no mesmo lugar?

O [Oleafly](https://oleafly.com) é um espaço de trabalho de desktop gratuito para LaTeX, Typst
e Markdown. Navegue pelos modelos, edite o código-fonte e mantenha o PDF compilado
ao lado do rascunho. Adicione citações, crie figuras ou trabalhe com um agente de IA
no projeto. Seus arquivos ficam no seu computador.

O aplicativo pode baixar esses pacotes quando você precisar. Você também pode trazer um projeto
existente para o Oleafly quando quiser continuar escrevendo nele.

**[Baixe o Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) ·
[Leia a documentação](https://oleafly.com/docs/) ·
[Conheça o README do aplicativo](https://github.com/Oleafly/Oleafly#readme)**

## Como a coleção está organizada

- `packs/<pack>/<template>/` contém os arquivos-fonte e um manifesto `template.json`.
- `catalog.json` lista os pacotes disponíveis para download e seus arquivos. Gere-o novamente com `node gen-catalog.mjs`.
- `docs/templates-*.md` contém os índices completos por mecanismo. Execute `node tools/build-template-index.mjs` para atualizá-los junto com as tabelas do README.
- Os pacotes `open-*` contêm modelos importados da comunidade e exemplos de pacotes. Os modelos iniciais originais ficam nos outros pacotes.
- `tools/website-template-ids.json` registra as páginas publicadas na galeria. Atualize-o a partir do sitemap do site com `node tools/build-template-index.mjs --refresh-gallery`.

## Adicione um modelo que alguém vai usar

Tem um layout para a sua área, um relatório mais claro ou um ponto de partida melhor
para uma palestra? [Abra um pull request](https://github.com/Oleafly/template-packs/pulls).
Leia o [guia de autoria](../../tools/AUTHORING.md), inclua a licença e a atribuição
exigida, se houver, e compile o modelo antes de compartilhá-lo.

Gere uma prévia com:

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

A ferramenta de prévia precisa do `pdftoppm` e do compilador correspondente. As prévias
de Markdown usam Pandoc e Tectonic. Depois, gere novamente o catálogo e os índices de modelos.

[Relate um modelo que não funciona](https://github.com/Oleafly/template-packs/issues)
informando o nome da pasta, a versão do seu compilador e o erro que apareceu. Uma pequena
correção pode poupar uma tarde inteira da próxima pessoa.

## Licenças e atribuição

Os modelos originais do Oleafly são **CC0-1.0**. Os modelos importados mantêm
as licenças de origem; verifique cada manifesto, o `SOURCE.json` e os arquivos de
licença incluídos antes de reutilizá-los ou redistribuí-los. Nenhuma licença única
substitui esses termos individuais.

Pacotes e fontes externos têm suas próprias licenças. Um modelo com o nome de
uma revista ou conferência, de uma instituição ou de um design conhecido não indica endosso.
Confira os requisitos oficiais atuais antes da submissão final.

Alguns modelos importados vieram sem nenhuma licença. Os manifestos deles dizem
"Unlicensed (no license stated)" (sem licença declarada) e o `SOURCE.json` aponta para
a origem do modelo. Se um deles for seu e você quiser que seja retirado,
[abra uma issue](https://github.com/Oleafly/template-packs/issues) com o
nome da pasta e nós o removemos, sem perguntas.
