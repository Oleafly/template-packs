## نقاط انطلاق جديدة

- **في Markdown:** [موجز بحثي](../../packs/markdown-starters/markdown-research-brief/)،
  و[مراجعة أدبيات](../../packs/markdown-starters/markdown-literature-review/)،
  و[تقرير تقني](../../packs/markdown-starters/markdown-technical-report/).
- **في Typst:** [تقرير لتحليل البيانات](../../packs/reports-lab/typst-data-analysis-report/)
  و[ملصق بحثي بمقاس A3](../../packs/slides-posters/typst-research-poster/)، وكلاهما يعتمد على ميزات Typst المدمجة.
- **في LaTeX:** [رسالة رد على المراجعين](../../packs/academic-writing/response-to-reviewers/)
  فيها التعليقات والردود ومواضع التعديل.

تأتي قوالب البداية الأصلية الستة هذه مع معاينات مرسومة، وترخيصها CC0-1.0.
وقد عُلّمت البيانات والمراسلات التي فيها على أنها أمثلة، لتضع عملك مكانها.

## استخدام قالب

اختر قالبًا واحتفظ بمجلده كاملًا، فالملفات المساندة قد تشمل ببليوغرافيا أو صورًا
أو ملفات أنماط أو أقسامًا إضافية من المستند.
راجع `template.json` وأي ملف `SOURCE.json` لمعرفة المترجم المطلوب والاعتماديات
وتعليمات المشروع الأصلي والترخيص.

للحصول على المجموعة:

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

افتح مجلد القالب في محررك. تبني الأوامر التالية قوالب البداية الجديدة، وتُشغَّل
من داخل مجلد كل قالب:

| الصيغة | بناء ملف PDF |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

ويمكن تحويل Markdown أيضًا إلى مستند Word بالأمر `pandoc main.md -o main.docx`،
أو إلى HTML بالأمر `pandoc main.md --standalone -o main.html`.
راجع [دليل Pandoc](https://pandoc.org/MANUAL.html) لخيارات التصدير،
و[الدرس التعليمي لـ Typst](https://typst.app/docs/tutorial/) إن كانت ملفات `.typ` جديدة عليك.

تشمل القوالب المستوردة من المجتمع إصدارات وأساليب كثيرة. يحتاج بعضها إلى محرك TeX
بعينه، أو خطوط مثبتة على الجهاز، أو حزم من سجل حزم خارجي. ووجود قالب
في الفهرس لا يعني أنه جُمّع بكل سلاسل الأدوات.

## اكتب وعاين في مكان واحد

تطبيق [Oleafly](https://oleafly.com) مساحة عمل مجانية على سطح المكتب لـ LaTeX وTypst
وMarkdown. تصفّح القوالب، وحرّر المصدر، وأبقِ ملف PDF المجمَّع بجانب مسودتك. أضف استشهادات،
أو أنشئ أشكالًا، أو اعمل مع وكيل ذكاء اصطناعي
على المشروع. وتبقى ملفاتك على حاسوبك.

يستطيع التطبيق تنزيل هذه الحزم عند الحاجة. ويمكنك أيضًا أن تُحضر مشروعًا موجودًا
إلى Oleafly إذا أردت مواصلة الكتابة فيه.

**[نزّل Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) ·
[اقرأ الأدلة](https://oleafly.com/docs/) ·
[تصفّح ملف README للتطبيق](https://github.com/Oleafly/Oleafly#readme)**

## تنظيم المجموعة

- يحتوي `packs/<pack>/<template>/` على ملفات المصدر وملف البيان `template.json`.
- يسرد `catalog.json` الحزم القابلة للتنزيل وملفاتها. أعد توليده بالأمر `node gen-catalog.mjs`.
- تحتوي ملفات `docs/templates-*.md` على الفهارس الكاملة لكل محرك. شغّل `node tools/build-template-index.mjs` لتحديثها مع جداول README.
- تضم حزم `open-*` قوالب مستوردة من المجتمع وأمثلة لاستخدام الحزم. أما قوالب البداية الأصلية فموجودة في الحزم الأخرى.
- يسجّل `tools/website-template-ids.json` صفحات المعرض المنشورة. حدّثه من خريطة الموقع بالأمر `node tools/build-template-index.mjs --refresh-gallery`.

## أضف قالبًا ينفع غيرك

هل لديك تخطيط يناسب مجالك، أو قالب تقرير أوضح، أو نقطة بداية أفضل
لعرض تقديمي؟ [افتح طلب سحب](https://github.com/Oleafly/template-packs/pulls).
اقرأ [دليل التأليف](../../tools/AUTHORING.md)، وأرفق الترخيص ونسبة العمل إلى أصحابه إن كانت مطلوبة،
وجمّع القالب قبل مشاركته.

أنشئ معاينة بالأمر التالي:

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

تحتاج أداة المعاينة إلى `pdftoppm` والمترجم المناسب. أما معاينات Markdown
فتعتمد على Pandoc وTectonic. بعد ذلك أعد توليد الكتالوج وفهارس القوالب.

[أبلغ عن قالب معطوب](https://github.com/Oleafly/template-packs/issues)
واذكر اسم مجلده وإصدار المترجم لديك والخطأ الذي ظهر لك. فإصلاح صغير
قد يوفّر على من يأتي بعدك نصف يوم.

## التراخيص ونسبة الأعمال

قوالب Oleafly الأصلية صادرة بترخيص **CC0-1.0**. أما القوالب المستوردة فتحتفظ بتراخيصها
الأصلية، لذا راجع ملف البيان لكل قالب و`SOURCE.json` وأي ملفات ترخيص مرفقة
قبل إعادة استخدامها أو إعادة توزيعها. ولا يوجد ترخيص واحد
يحل محل هذه الشروط الخاصة بكل قالب.

للحزم والخطوط الخارجية تراخيصها الخاصة. وتسمية قالب باسم جهة نشر أو مؤسسة
أو تصميم معروف لا تعني أن صاحب الاسم يعتمده. راجع المتطلبات الرسمية الحالية
قبل التقديم النهائي.

جاءت بعض القوالب المستوردة بلا أي ترخيص. ملفات البيان الخاصة بها تذكر
"Unlicensed (no license stated)"، أي بلا ترخيص معلن، ويشير `SOURCE.json` إلى المكان الذي جاء منه
القالب. إذا كان أحدها لك وتريد حذفه،
[افتح مشكلة](https://github.com/Oleafly/template-packs/issues) واذكر
اسم المجلد، وسنحذفه دون أن نسألك عن السبب.
