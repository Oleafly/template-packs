Тратьте меньше времени на оформление страницы. Найдите основу для следующей статьи,
диссертации, резюме, доклада, постера или отчёта и доработайте её под себя.

Здесь собраны наборы шаблонов под открытыми лицензиями, которыми можно пользоваться в своём
редакторе и со своим компилятором. Исходники самые обычные: файлы `.tex`, `.typ` и `.md`.
Oleafly для этого не нужен.

## Новые стартовые шаблоны

- **Markdown:** [исследовательская записка](../../packs/markdown-starters/markdown-research-brief/),
  [обзор литературы](../../packs/markdown-starters/markdown-literature-review/) и
  [технический отчёт](../../packs/markdown-starters/markdown-technical-report/).
- **Typst:** [отчёт по анализу данных](../../packs/reports-lab/typst-data-analysis-report/)
  и [исследовательский постер A3](../../packs/slides-posters/typst-research-poster/). Оба сделаны на встроенных возможностях Typst.
- **LaTeX:** [письмо с ответом рецензентам](../../packs/academic-writing/response-to-reviewers/)
  с замечаниями, ответами и указанием мест правок.

Все шесть оригинальных стартовых шаблонов идут с готовыми превью и распространяются по лицензии CC0-1.0.
Примеры данных и переписки помечены, чтобы их было легко заменить своими материалами.

## Как использовать шаблон

Выберите шаблон и копируйте его папку целиком. Среди вспомогательных файлов
могут быть библиография, изображения, стили или дополнительные разделы документа.
Нужный компилятор, зависимости, инструкции авторов оригинала и лицензию смотрите
в `template.json` и в `SOURCE.json`, если он есть.

Получить коллекцию можно так:

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

Откройте папку шаблона в редакторе. Новые стартовые шаблоны собираются такими командами,
если запускать их из папки шаблона:

| Формат | Сборка PDF |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

Из Markdown также можно получить документ Word командой `pandoc main.md -o main.docx`
или HTML командой `pandoc main.md --standalone -o main.html`.
Параметры экспорта описаны в [руководстве Pandoc](https://pandoc.org/MANUAL.html), а если вы впервые
работаете с файлами `.typ`, загляните в [учебник Typst](https://typst.app/docs/tutorial/).

Шаблоны, импортированные из сообщества, бывают самых разных версий и стилей. Для некоторых
нужны определённый движок TeX, установленные шрифты или пакеты из внешнего реестра. Если шаблон
есть в списке, это не значит, что его компилировали всеми возможными инструментами.

## Как устроена коллекция

- `packs/<pack>/<template>/` содержит исходные файлы и манифест `template.json`.
- `catalog.json` перечисляет наборы для скачивания и их файлы. Чтобы сгенерировать его заново, запустите `node gen-catalog.mjs`.
- `docs/templates-*.md` содержат полные списки шаблонов по движкам. Команда `node tools/build-template-index.mjs` обновляет их и таблицы в README.
- Наборы `open-*` содержат импортированные шаблоны сообщества и примеры к пакетам. Оригинальные стартовые шаблоны лежат в остальных наборах.
- `tools/website-template-ids.json` хранит список опубликованных страниц галереи. Обновить его по карте сайта можно командой `node tools/build-template-index.mjs --refresh-gallery`.

## Добавьте шаблон, который кому-то пригодится

Есть макет для вашей области, более понятный отчёт или удачная основа
для доклада? [Откройте pull request](https://github.com/Oleafly/template-packs/pulls).
Прочитайте [руководство для авторов](../../tools/AUTHORING.md), приложите лицензию
и нужную атрибуцию, а перед отправкой соберите шаблон.

Сгенерировать превью можно так:

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

Для превью нужны `pdftoppm` и подходящий компилятор. Превью для Markdown
собираются через Pandoc и Tectonic. Затем заново сгенерируйте каталог и списки шаблонов.

[Сообщите о сломанном шаблоне](https://github.com/Oleafly/template-packs/issues),
указав имя его папки, версию вашего компилятора и полученную ошибку. Небольшое
исправление может сберечь следующему человеку полдня.

## Лицензии и указание авторства

Оригинальные шаблоны Oleafly распространяются под **CC0-1.0**. Импортированные шаблоны сохраняют
лицензии своих авторов. Прежде чем использовать их повторно или распространять, проверьте манифест,
`SOURCE.json` и приложенные файлы лицензий. Единой лицензии, которая заменила бы
эти отдельные условия, нет.

У внешних пакетов и шрифтов свои лицензии. Если в названии шаблона есть конференция, журнал,
организация или известный стиль оформления, это не означает их одобрения. Перед окончательной
отправкой сверьтесь с актуальными официальными требованиями.

Некоторые импортированные шаблоны пришли вообще без лицензии. В их манифестах стоит
«Unlicensed (no license stated)» (без лицензии), а `SOURCE.json` ссылается на источник
шаблона. Если один из них ваш и вы хотите его убрать,
[откройте issue](https://github.com/Oleafly/template-packs/issues), указав имя
папки, и мы удалим шаблон без лишних вопросов.
