artículo, tesis, currículum, charla, póster o informe, y hazlo tuyo.

tu propio editor y compilador. Los archivos fuente son `.tex`, `.typ` y `.md` normales
y corrientes. Oleafly es opcional.

## Nuevos puntos de partida

- **Markdown:** un [informe breve de investigación](../../packs/markdown-starters/markdown-research-brief/),
  una [revisión bibliográfica](../../packs/markdown-starters/markdown-literature-review/) y
  un [informe técnico](../../packs/markdown-starters/markdown-technical-report/).
- **Typst:** un [informe de análisis de datos](../../packs/reports-lab/typst-data-analysis-report/)
  y un [póster de investigación A3](../../packs/slides-posters/typst-research-poster/), hechos con funciones integradas de Typst.
- **LaTeX:** una [carta de respuesta a los revisores](../../packs/academic-writing/response-to-reviewers/)
  con comentarios, respuestas y la ubicación de cada cambio.

Estas seis plantillas iniciales son originales, incluyen vistas previas renderizadas y usan CC0-1.0.
Los datos y la correspondencia de ejemplo están marcados para que puedas sustituirlos por tu propio trabajo.

## Cómo usar una plantilla

Elige una plantilla y conserva su carpeta completa. Entre los archivos auxiliares
puede haber una bibliografía, imágenes, estilos o secciones adicionales del documento.
Consulta `template.json` y, si existe, `SOURCE.json` para ver el compilador previsto,
las dependencias, las instrucciones del proyecto original y la licencia.

Para obtener la colección:

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

Abre una carpeta de plantilla en tu editor. Estos comandos compilan las nuevas plantillas
iniciales desde dentro de sus carpetas:

| Formato | Generar un PDF |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

Markdown también se puede convertir en un documento de Word con `pandoc main.md -o main.docx`,
o en HTML con `pandoc main.md --standalone -o main.html`.
Consulta la [guía de Pandoc](https://pandoc.org/MANUAL.html) para ver las opciones de exportación y el
[tutorial de Typst](https://typst.app/docs/tutorial/) si es la primera vez que usas archivos `.typ`.

Las plantillas importadas de la comunidad abarcan muchas versiones y estilos. Algunas necesitan
un motor de TeX concreto, fuentes instaladas o paquetes de un registro externo. Que una plantilla
aparezca en el índice no significa que se haya compilado con todas las cadenas de herramientas.

## ¿Quieres escribir y ver el resultado en un mismo sitio?

[Oleafly](https://oleafly.com) es un espacio de trabajo de escritorio gratuito para LaTeX, Typst
y Markdown. Explora plantillas, edita el código fuente y ten el PDF compilado
junto a tu borrador. Añade citas, crea figuras o trabaja con un agente de IA
en el proyecto. Tus archivos se quedan en tu ordenador.

La aplicación puede descargar estos paquetes cuando los necesites. También puedes traer
a Oleafly un proyecto existente si quieres seguir escribiendo allí.

**[Descarga Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) ·
[Lee la documentación](https://oleafly.com/docs/) ·
[Consulta el README de la aplicación](https://github.com/Oleafly/Oleafly#readme)**

## Cómo se organiza la colección

- `packs/<pack>/<template>/` contiene los archivos fuente y un manifiesto `template.json`.
- `catalog.json` enumera los paquetes descargables y sus archivos. Regenéralo con `node gen-catalog.mjs`.
- `docs/templates-*.md` contiene los índices completos por motor. Ejecuta `node tools/build-template-index.mjs` para actualizarlos junto con las tablas del README.
- Los paquetes `open-*` contienen plantillas importadas de la comunidad y ejemplos de paquetes. Las plantillas iniciales originales están en los demás paquetes.
- `tools/website-template-ids.json` registra las páginas publicadas en la galería. Actualízalo a partir del sitemap del sitio web con `node tools/build-template-index.mjs --refresh-gallery`.

## Añade una plantilla que alguien vaya a usar

¿Tienes un diseño para tu disciplina, un informe más claro o un punto de partida mejor
para una charla? [Abre una pull request](https://github.com/Oleafly/template-packs/pulls).
Lee la [guía de autoría](../../tools/AUTHORING.md), incluye la licencia y la atribución
que haga falta, y compila la plantilla antes de compartirla.

Genera una vista previa con:

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

La herramienta de vistas previas necesita `pdftoppm` y el compilador correspondiente. Las vistas previas
de Markdown usan Pandoc y Tectonic. Después, regenera el catálogo y los índices de plantillas.

[Informa de una plantilla que no funciona](https://github.com/Oleafly/template-packs/issues)
indicando el nombre de su carpeta, la versión de tu compilador y el error que apareció. Un pequeño
arreglo puede ahorrarle una tarde entera a la siguiente persona.

## Licencias y atribución

Las plantillas originales de Oleafly son **CC0-1.0**. Las plantillas importadas conservan
las licencias de su origen; revisa cada manifiesto, `SOURCE.json` y cualquier archivo de
licencia incluido antes de reutilizarlas o redistribuirlas. Ninguna licencia única
sustituye a esas condiciones individuales.

Los paquetes y las fuentes externos tienen sus propias licencias. Que una plantilla lleve el nombre
de una revista o un congreso, una institución o un diseño conocido no significa que la respalden.
Consulta los requisitos oficiales vigentes antes del envío final.

Algunas plantillas importadas llegaron sin ninguna licencia. Sus manifiestos indican
"Unlicensed (no license stated)" (sin licencia declarada) y `SOURCE.json` enlaza al lugar de donde
procede la plantilla. Si una de ellas es tuya y quieres que la retiremos,
[abre una incidencia](https://github.com/Oleafly/template-packs/issues) con el
nombre de la carpeta y la eliminaremos sin hacer preguntas.
