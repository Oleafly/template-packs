[Deutsch](README.de.md) | [English](../../README.md) | [Español](README.es.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Português](README.pt.md) | [Русский](README.ru.md) | **中文** | [العربية](README.ar.md)

少花点时间在版面设置上。为你的下一篇论文、学位论文、简历、演讲、海报或报告找一个起点，再把它改成你自己的。

这是一套采用开放许可的模板包，可以搭配你自己的编辑器和编译器使用。源文件就是普通的 `.tex`、`.typ` 和 `.md` 文件，不一定要用 Oleafly。

找到想留着用的版式了？[给这个合集点个星标](https://github.com/Oleafly/template-packs)，以后就能很快找回来，也能帮其他写作者找到起点。

## 新增起始模板

- **Markdown**：[研究简报](../../packs/markdown-starters/markdown-research-brief/)、[文献综述](../../packs/markdown-starters/markdown-literature-review/)和[技术报告](../../packs/markdown-starters/markdown-technical-report/)。
- **Typst**：[数据分析报告](../../packs/reports-lab/typst-data-analysis-report/)和 [A3 研究海报](../../packs/slides-posters/typst-research-poster/)，只用到 Typst 的内置功能。
- **LaTeX**：[审稿意见回复信](../../packs/academic-writing/response-to-reviewers/)，包含审稿意见、逐条回复和修改位置。

这六个原创起始模板都附有渲染好的预览，采用 CC0-1.0 许可。示例数据和信件都标注为示例，方便你换成自己的内容。

## 使用模板

选好模板后，请完整保留它的文件夹。辅助文件可能包括参考文献、图片、样式，或文档的其他章节。预期使用的编译器、依赖、上游说明和许可证，请查看 `template.json` 和 `SOURCE.json`（如果有）。

获取整个合集：

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

在编辑器中打开模板文件夹。在各个新起始模板自己的文件夹里运行下面的命令，就能生成 PDF：

| 格式 | 生成 PDF |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

Markdown 还可以用 `pandoc main.md -o main.docx` 转成 Word 文档，或用 `pandoc main.md --standalone -o main.html` 转成 HTML。导出选项见 [Pandoc 手册](https://pandoc.org/MANUAL.html)；如果你刚开始接触 `.typ` 文件，可以先看 [Typst 教程](https://typst.app/docs/tutorial/)。

社区导入的模板版本众多，风格各异。有些需要特定的 TeX 引擎、已安装的字体，或来自上游仓库的包。出现在索引里，并不代表它在每一种工具链上都编译过。

## 想在同一处写作和预览？

[Oleafly](https://oleafly.com) 是一款免费的桌面工作空间，支持 LaTeX、Typst 和 Markdown。你可以浏览模板、编辑源文件，并让编译好的 PDF 一直显示在草稿旁边。还可以添加引文、制作图表，或者和 AI 代理一起处理项目。文件始终保存在你自己的电脑上。

应用可以按需下载这些模板包。如果想在 Oleafly 里接着写，也可以把已有项目导入进来。

## 合集结构

- `packs/<pack>/<template>/` 包含源文件和 `template.json` 清单。
- `catalog.json` 列出可下载的模板包及其文件。用 `node gen-catalog.mjs` 重新生成。
- `docs/templates-*.md` 是按引擎划分的完整索引。运行 `node tools/build-template-index.mjs` 可以刷新这些索引和 README 中的表格。
- `open-*` 模板包收录社区导入的模板和宏包示例。原创起始模板放在其余模板包中。
- `tools/website-template-ids.json` 记录已发布的模板库页面。用 `node tools/build-template-index.mjs --refresh-gallery` 根据网站的 sitemap 刷新它。

## 添加别人用得上的模板

你有适合自己领域的版式、更清楚的报告模板，或者更好用的演讲起点吗？欢迎[提交 pull request](https://github.com/Oleafly/template-packs/pulls)。请先阅读[模板编写指南](../../tools/AUTHORING.md)，附上许可证和必要的署名，并在分享之前编译一遍模板。

用下面的命令生成预览：

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

预览工具需要 `pdftoppm` 和对应的编译器。Markdown 预览使用 Pandoc 和 Tectonic。之后再重新生成目录文件和模板索引。

[报告有问题的模板](https://github.com/Oleafly/template-packs/issues)时，请写明它的文件夹名称、你的编译器版本和看到的错误。一个小修复，也许就能帮下一个人省下一个下午。

## 许可证与署名

Oleafly 原创模板采用 **CC0-1.0**。导入的模板保留各自的上游许可证；重用或再分发之前，请查看每个模板的清单、`SOURCE.json` 和附带的许可证文件。没有哪一个许可证能取代这些各自的条款。

外部包和字体有各自的许可证。以会议、期刊、机构或知名设计命名的模板，并不代表得到了对方的认可。最终投稿前，请核对最新的官方要求。

有些导入的模板原本就没有任何许可证。它们的清单写着 "Unlicensed (no license stated)"（无许可证，未声明授权），`SOURCE.json` 则链接回模板的原始出处。如果其中某个模板是你的，并且你希望撤下它，请[提交 issue](https://github.com/Oleafly/template-packs/issues) 并写明文件夹名称，我们会直接删除，无需任何解释。
