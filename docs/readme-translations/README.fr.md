# Packs de modèles LaTeX, Typst et Markdown

[Deutsch](README.de.md) | [English](../../README.md) | [Español](README.es.md) | **Français** | [日本語](README.ja.md) | [한국어](README.ko.md) | [Português](README.pt.md) | [Русский](README.ru.md) | [中文](README.zh.md) | [العربية](README.ar.md)

Passez moins de temps sur la mise en page. Trouvez un point de départ pour un article,
une thèse, un CV, un exposé, un poster ou un rapport, puis adaptez-le à votre façon.

Cette collection rassemble des packs de modèles sous licence ouverte, à utiliser avec
l'éditeur et le compilateur de votre choix. Les sources sont de simples fichiers `.tex`, `.typ`
et `.md`. Oleafly est facultatif.

**[Parcourir la galerie](https://oleafly.com/templates/) ·
[Choisir un moteur](#index-des-modèles) ·
[Télécharger la collection](https://github.com/Oleafly/template-packs/archive/refs/heads/main.zip)**

Vous avez trouvé une mise en page à garder ? [Ajoutez une étoile à cette collection](https://github.com/Oleafly/template-packs)
pour la retrouver facilement et aider d'autres auteurs à se lancer.

## Nouveaux points de départ

- **Markdown :** une [note de recherche](../../packs/markdown-starters/markdown-research-brief/),
  une [revue de littérature](../../packs/markdown-starters/markdown-literature-review/) et
  un [rapport technique](../../packs/markdown-starters/markdown-technical-report/).
- **Typst :** un [rapport d'analyse de données](../../packs/reports-lab/typst-data-analysis-report/)
  et un [poster de recherche A3](../../packs/slides-posters/typst-research-poster/), réalisés avec les fonctionnalités natives de Typst.
- **LaTeX :** une [lettre de réponse aux évaluateurs](../../packs/academic-writing/response-to-reviewers/)
  avec les commentaires, les réponses et l'emplacement des modifications.

Nous avons écrit ces six modèles de démarrage nous-mêmes. Ils incluent un aperçu du rendu et sont publiés sous CC0-1.0.
Les données et la correspondance d'exemple sont signalées comme telles, pour que vous puissiez les remplacer par votre propre travail.

## Utiliser un modèle

Choisissez un modèle et conservez son dossier au complet. Les fichiers annexes
peuvent comprendre une bibliographie, des images, des styles ou d'autres sections du document.
Consultez `template.json` et, s'il existe, `SOURCE.json` pour connaître le compilateur prévu,
les dépendances, les instructions du projet d'origine et la licence.

Pour récupérer la collection :

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

Ouvrez un dossier de modèle dans votre éditeur. Ces commandes, lancées depuis le dossier
de chaque modèle, compilent les nouveaux modèles de démarrage :

| Format | Générer un PDF |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

Un fichier Markdown peut aussi devenir un document Word avec `pandoc main.md -o main.docx`,
ou une page HTML avec `pandoc main.md --standalone -o main.html`.
Consultez le [manuel de Pandoc](https://pandoc.org/MANUAL.html) pour les options d'export, et le
[tutoriel de Typst](https://typst.app/docs/tutorial/) si vous découvrez les fichiers `.typ`.

Les modèles importés de la communauté couvrent de nombreuses versions et de nombreux styles. Certains
exigent un moteur TeX particulier, des polices installées ou des paquets issus d'un registre externe. Figurer
dans l'index ne signifie pas qu'un modèle a été compilé avec toutes les chaînes d'outils.

## Écrire et prévisualiser au même endroit ?

[Oleafly](https://oleafly.com) est une application de bureau gratuite pour LaTeX, Typst
et Markdown. Parcourez les modèles, modifiez la source et gardez le PDF compilé à côté
de votre brouillon. Ajoutez des citations, créez des figures ou travaillez sur le projet avec un agent IA.
Vos fichiers restent sur votre ordinateur.

L'application peut télécharger ces packs à la demande. Vous pouvez aussi importer un projet
existant dans Oleafly si vous souhaitez continuer à y écrire.

**[Télécharger Oleafly](https://github.com/Oleafly/Oleafly/releases/latest) ·
[Lire la documentation](https://oleafly.com/docs/) ·
[Découvrir le README de l'application](https://github.com/Oleafly/Oleafly#readme)**

## Organisation de la collection

- `packs/<pack>/<template>/` contient les fichiers source et un manifeste `template.json`.
- `catalog.json` répertorie les packs téléchargeables et leurs fichiers. Régénérez-le avec `node gen-catalog.mjs`.
- `docs/templates-*.md` contient les index complets par moteur. Lancez `node tools/build-template-index.mjs` pour les mettre à jour, ainsi que les tableaux du README.
- Les packs `open-*` contiennent des modèles importés de la communauté et des exemples de paquets. Nos propres modèles de démarrage se trouvent dans les autres packs.
- `tools/website-template-ids.json` recense les pages publiées de la galerie. Mettez-le à jour à partir du plan du site web avec `node tools/build-template-index.mjs --refresh-gallery`.

## Proposer un modèle qui servira

Vous avez une mise en page pour votre discipline, un rapport plus clair ou un meilleur point de départ
pour un exposé ? [Ouvrez une pull request](https://github.com/Oleafly/template-packs/pulls).
Lisez le [guide de création des modèles](../../tools/AUTHORING.md), indiquez la licence et toute attribution
requise, et compilez le modèle avant de le partager.

Générez un aperçu avec :

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

L'outil d'aperçu a besoin de `pdftoppm` et du compilateur correspondant. Les aperçus Markdown
utilisent Pandoc et Tectonic. Régénérez ensuite le catalogue et les index des modèles.

[Signalez un modèle défectueux](https://github.com/Oleafly/template-packs/issues)
en indiquant le nom de son dossier, la version de votre compilateur et l'erreur obtenue. Une petite
correction peut faire gagner un après-midi à la personne suivante.

nom du dossier : nous le supprimerons, sans poser de questions.
