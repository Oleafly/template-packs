ページの体裁づくりにかける時間を減らしましょう。次の論文、学位論文、履歴書、発表スライド、ポスター、レポートの出発点をここで見つけて、自分の文書に仕上げてください。

オープンなライセンスで公開しているテンプレートパックのコレクションです。お使いのエディタとコンパイラでそのまま使えます。ソースは普通の`.tex`、`.typ`、`.md`ファイルで、Oleaflyは必須ではありません。

[エンジンを選ぶ](#テンプレート一覧) ·
[コレクションをダウンロード](https://github.com/Oleafly/template-packs/archive/refs/heads/main.zip)**

残しておきたいレイアウトが見つかったら、[このコレクションにスターを付けて](https://github.com/Oleafly/template-packs)おきましょう。あとで見つけやすくなり、ほかの書き手がここから書き始めるきっかけにもなります。

## 新しいスターター

- **Markdown:** [リサーチブリーフ](../../packs/markdown-starters/markdown-research-brief/)、[文献レビュー](../../packs/markdown-starters/markdown-literature-review/)、[技術レポート](../../packs/markdown-starters/markdown-technical-report/)。
- **Typst:** [データ分析レポート](../../packs/reports-lab/typst-data-analysis-report/)と[A3の研究ポスター](../../packs/slides-posters/typst-research-poster/)。どちらもTypstの組み込み機能で作っています。
- **LaTeX:** 査読コメント、回答、修正箇所をまとめられる[査読者への回答書](../../packs/academic-writing/response-to-reviewers/)。

この6つのオリジナルスターターには、レンダリング済みのプレビューが付いています。ライセンスはCC0-1.0です。例として入れたデータや文面にはサンプルだと分かる表示があるので、自分の内容に置き換えてください。

## テンプレートを使う

テンプレートを選んだら、フォルダーごとまとめて使ってください。フォルダーには、参考文献、画像、スタイル、別ファイルに分けた本文などの補助ファイルが入っていることがあります。想定しているコンパイラ、依存関係、配布元の説明、ライセンスは、`template.json`と、あれば`SOURCE.json`で確認できます。

コレクションを入手するには、次を実行します。

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

テンプレートのフォルダーをエディタで開いてください。新しいスターターは、それぞれのフォルダー内で次のコマンドを実行するとビルドできます。

| 形式 | PDFをビルド |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

Markdownは、`pandoc main.md -o main.docx`でWord文書に、`pandoc main.md --standalone -o main.html`でHTMLにも変換できます。エクスポートのオプションは[Pandocのガイド](https://pandoc.org/MANUAL.html)を、`.typ`ファイルが初めてなら[Typstのチュートリアル](https://typst.app/docs/tutorial/)を参照してください。

コミュニティから取り込んだテンプレートは、バージョンもスタイルもさまざまです。特定のTeXエンジン、インストール済みのフォント、配布元のレジストリにあるパッケージが必要なものもあります。一覧に載っていても、すべてのツールチェーンでコンパイルを確認したわけではありません。

## 執筆とプレビューを1か所で済ませたいなら

[Oleafly](https://oleafly.com)は、LaTeX、Typst、Markdownのための無料のデスクトップワークスペースです。テンプレートを探してソースを編集し、コンパイルしたPDFを原稿の隣に表示できます。引用の追加や図の作成、AIエージェントとのプロジェクト作業もできます。ファイルはお使いのコンピューターに残ります。

アプリからは、これらのパックを必要なときにダウンロードできます。既存のプロジェクトをOleaflyに取り込んで、続きをそこで書くこともできます。

**[Oleaflyをダウンロード](https://github.com/Oleafly/Oleafly/releases/latest) ·
[ドキュメントを読む](https://oleafly.com/docs/) ·
[アプリのREADMEを見る](https://github.com/Oleafly/Oleafly#readme)**

## コレクションの構成

- `packs/<pack>/<template>/`には、ソースファイルと`template.json`マニフェストが入っています。
- `catalog.json`は、ダウンロードできるパックとそのファイルの一覧です。`node gen-catalog.mjs`で再生成します。
- `docs/templates-*.md`には、エンジンごとの完全な一覧があります。これらとREADMEの表を更新するには、`node tools/build-template-index.mjs`を実行します。
- `open-*`パックには、コミュニティから取り込んだテンプレートとパッケージのサンプルが入っています。オリジナルのスターターは、それ以外のパックにあります。
- `tools/website-template-ids.json`には、公開済みのギャラリーページが記録されています。ウェブサイトのサイトマップから更新するには、`node tools/build-template-index.mjs --refresh-gallery`を実行します。

## 誰かの役に立つテンプレートを追加する

自分の分野に合うレイアウト、もっと分かりやすいレポート、発表の出発点として使いやすいテンプレートがあれば、[プルリクエストを作成](https://github.com/Oleafly/template-packs/pulls)してください。[作成ガイド](../../tools/AUTHORING.md)を読み、ライセンスと必要なクレジット表示を含めて、共有する前にテンプレートをコンパイルしてください。

プレビューは次のコマンドで生成します。

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

プレビューツールには、`pdftoppm`と対応するコンパイラが必要です。Markdownのプレビューには、PandocとTectonicを使います。生成したら、カタログとテンプレート一覧を再生成してください。

[動かないテンプレートを報告](https://github.com/Oleafly/template-packs/issues)するときは、フォルダー名、コンパイラのバージョン、表示されたエラーを添えてください。小さな修正でも、次の人が半日を無駄にせずに済むかもしれません。

## ライセンスとクレジット表示

Oleaflyオリジナルのテンプレートは**CC0-1.0**です。取り込んだテンプレートには、配布元のライセンスがそのまま適用されます。再利用や再配布の前に、各マニフェスト、`SOURCE.json`、同梱のライセンスファイルを確認してください。それぞれの条件をまとめて置き換える単一のライセンスはありません。

外部のパッケージやフォントには、それぞれ独自のライセンスがあります。投稿先、機関、定番のデザインにちなんだ名前のテンプレートでも、その投稿先や機関が推奨しているわけではありません。最終的に提出する前に、最新の公式要件を確認してください。

取り込んだテンプレートの中には、ライセンスがまったく付いていなかったものもあります。そうしたテンプレートのマニフェストには「Unlicensed (no license stated)」（ライセンスの記載なし）と書かれており、`SOURCE.json`には入手元へのリンクがあります。その中にご自身のテンプレートがあり、取り下げを希望する場合は、フォルダー名を添えて[Issueを作成](https://github.com/Oleafly/template-packs/issues)してください。理由は問わずに削除します。
