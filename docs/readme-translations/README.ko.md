# LaTeX, Typst, Markdown 템플릿 팩

[Deutsch](README.de.md) | [English](../../README.md) | [Español](README.es.md) | [Français](README.fr.md) | [日本語](README.ja.md) | **한국어** | [Português](README.pt.md) | [Русский](README.ru.md) | [中文](README.zh.md) | [العربية](README.ar.md)

페이지 서식을 잡는 데 드는 시간을 줄여 보세요. 다음 논문, 학위 논문, 이력서, 발표 자료, 포스터, 보고서에 쓸 출발점을 찾아 내 문서로 다듬으면 됩니다.

평소 쓰는 편집기와 컴파일러에서 사용할 수 있는 오픈 라이선스 템플릿 팩 모음입니다. 소스는 평범한 `.tex`, `.typ`, `.md` 파일이며, Oleafly는 선택 사항입니다.

계속 쓰고 싶은 레이아웃을 찾았다면 [이 컬렉션에 별을 눌러](https://github.com/Oleafly/template-packs) 두세요. 나중에 다시 찾기 쉽고, 다른 사람이 글쓰기를 시작하는 데도 도움이 됩니다.

## 새 시작 템플릿

- **Markdown:** [연구 브리프](../../packs/markdown-starters/markdown-research-brief/), [문헌 검토](../../packs/markdown-starters/markdown-literature-review/), [기술 보고서](../../packs/markdown-starters/markdown-technical-report/).
- **Typst:** [데이터 분석 보고서](../../packs/reports-lab/typst-data-analysis-report/)와 [A3 연구 포스터](../../packs/slides-posters/typst-research-poster/). 둘 다 Typst 내장 기능으로 만들었습니다.
- **LaTeX:** 심사위원 의견, 답변, 수정 위치를 함께 정리하는 [심사 의견 답변서](../../packs/academic-writing/response-to-reviewers/).

이 여섯 가지 오리지널 시작 템플릿에는 렌더링된 미리보기가 들어 있고, 라이선스는 CC0-1.0입니다. 예시 데이터와 서신 내용에는 예시라고 표시해 두었으니 내 작업으로 바꿔 넣으면 됩니다.

## 템플릿 사용하기

템플릿을 고른 뒤에는 폴더 전체를 함께 두세요. 폴더에는 참고문헌, 이미지, 스타일, 추가 문서 섹션 같은 보조 파일이 들어 있을 수 있습니다. 의도한 컴파일러, 의존성, 원본 배포처의 안내, 라이선스는 `template.json`과 (있다면) `SOURCE.json`에서 확인하세요.

컬렉션 전체를 받으려면 다음을 실행하세요.

```sh
git clone --depth 1 https://github.com/Oleafly/template-packs.git
```

편집기에서 템플릿 폴더를 여세요. 새 시작 템플릿은 각 폴더 안에서 다음 명령으로 빌드합니다.

| 형식 | PDF 빌드 |
| --- | --- |
| LaTeX | `tectonic main.tex` |
| Typst | `typst compile main.typ main.pdf` |
| Markdown | `pandoc main.md --standalone --citeproc --pdf-engine=tectonic -o main.pdf` |

Markdown은 `pandoc main.md -o main.docx`로 Word 문서로, `pandoc main.md --standalone -o main.html`로 HTML로도 변환할 수 있습니다. 내보내기 옵션은 [Pandoc 가이드](https://pandoc.org/MANUAL.html)를, `.typ` 파일이 처음이라면 [Typst 튜토리얼](https://typst.app/docs/tutorial/)을 참고하세요.

커뮤니티에서 가져온 템플릿은 버전과 스타일이 다양합니다. 일부는 특정 TeX 엔진, 설치된 글꼴, 원본 레지스트리의 패키지가 필요합니다. 목록에 있다고 해서 모든 도구 체인에서 컴파일해 본 것은 아닙니다.

## 한곳에서 쓰고 미리 보고 싶다면

[Oleafly](https://oleafly.com)는 LaTeX, Typst, Markdown을 위한 무료 데스크톱 작업 공간입니다. 템플릿을 둘러보고, 소스를 편집하고, 컴파일된 PDF를 초안 옆에 두고 볼 수 있습니다. 인용을 추가하거나 그림을 만들거나 AI 에이전트와 함께 프로젝트 작업을 할 수도 있습니다. 파일은 내 컴퓨터에 그대로 남습니다.

앱에서 필요할 때 이 팩들을 내려받을 수 있습니다. 기존 프로젝트를 Oleafly로 가져와 이어서 쓸 수도 있습니다.

## 컬렉션 구성

- `packs/<pack>/<template>/`에는 소스 파일과 `template.json` 매니페스트가 있습니다.
- `catalog.json`은 다운로드할 수 있는 팩과 그 파일의 목록입니다. `node gen-catalog.mjs`로 다시 생성합니다.
- `docs/templates-*.md`에는 엔진별 전체 목록이 있습니다. 이 목록과 README 표를 새로 고치려면 `node tools/build-template-index.mjs`를 실행하세요.
- `open-*` 팩에는 커뮤니티에서 가져온 템플릿과 패키지 예제가 들어 있습니다. 오리지널 시작 템플릿은 나머지 팩에 있습니다.
- `tools/website-template-ids.json`은 게시된 갤러리 페이지를 기록합니다. 웹사이트 사이트맵에서 새로 고치려면 `node tools/build-template-index.mjs --refresh-gallery`를 실행하세요.

## 누군가에게 쓸모 있는 템플릿 추가하기

내 분야에 맞는 레이아웃, 더 읽기 쉬운 보고서, 발표를 시작하기 좋은 템플릿이 있다면 [풀 리퀘스트를 열어 주세요](https://github.com/Oleafly/template-packs/pulls). [작성 가이드](../../tools/AUTHORING.md)를 읽고, 라이선스와 필요한 저작자 표시를 포함하고, 공유하기 전에 템플릿을 컴파일해 보세요.

미리보기는 다음 명령으로 생성합니다.

```sh
node tools/build-previews.mjs packs/<pack>/<template>
```

미리보기 도구에는 `pdftoppm`과 해당 컴파일러가 필요합니다. Markdown 미리보기는 Pandoc과 Tectonic을 사용합니다. 그다음 카탈로그와 템플릿 목록을 다시 생성하세요.

[작동하지 않는 템플릿을 신고할](https://github.com/Oleafly/template-packs/issues) 때는 폴더 이름, 컴파일러 버전, 표시된 오류를 함께 적어 주세요. 작은 수정 하나가 다음 사람의 반나절을 아껴 줄 수 있습니다.

## 라이선스와 저작자 표시

Oleafly 오리지널 템플릿은 **CC0-1.0**입니다. 가져온 템플릿은 원본 라이선스를 그대로 따릅니다. 재사용하거나 재배포하기 전에 각 매니페스트, `SOURCE.json`, 포함된 라이선스 파일을 확인하세요. 이런 개별 조건을 한꺼번에 대신하는 단일 라이선스는 없습니다.

외부 패키지와 글꼴에는 각각의 라이선스가 있습니다. 학회나 학술지, 기관, 잘 알려진 디자인의 이름을 딴 템플릿이라도 해당 학회나 기관이 보증한다는 뜻은 아닙니다. 최종 제출 전에는 현재 공식 요구 사항을 확인하세요.

가져온 템플릿 중에는 라이선스가 전혀 없이 공개된 것도 있습니다. 이런 템플릿의 매니페스트에는 "Unlicensed (no license stated)"(라이선스 명시 없음)라고 적혀 있고, `SOURCE.json`에는 템플릿 출처로 가는 링크가 있습니다. 그중에 본인의 템플릿이 있어 내리기를 원한다면 폴더 이름과 함께 [이슈를 열어 주세요](https://github.com/Oleafly/template-packs/issues). 이유를 묻지 않고 삭제하겠습니다.
