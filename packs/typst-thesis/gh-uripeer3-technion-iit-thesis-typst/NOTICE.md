# Notice

This project is an original Typst implementation inspired by the public
`eyalroz/technion-iit-thesis` LaTeX template.

Reference project:

- Repository: https://github.com/eyalroz/technion-iit-thesis
- Maintainer noted upstream: Eyal Rozenberg
- Original author noted upstream: Dan Kenigsberg
- Contributor noted upstream: Ido Tal

Most implementation code and supporting sample text in this port is original.
The main-matter example files intentionally track the upstream sample thesis
content so users can compare the LaTeX and Typst workflows side by side.

The files under `main/` are Typst translations/adaptations of the upstream
LaTeX sample chapter files. The sample graphics `graphics/mygraphic1.pdf` and
`graphics/mygraphic2.png` are copied from the upstream reference repository to
preserve sample-document parity. Review the upstream repository's licensing
status before redistributing these adapted sample materials.
