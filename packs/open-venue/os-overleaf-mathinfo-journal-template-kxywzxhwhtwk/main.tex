\section{Format} \label{form}
The paper format and style must be in accordance with the present document. You can use
this \LaTeX{} file to generate your camera-ready paper. The format and style
specifications are:
\begin{itemize}
\item A4-size, one column, text width 155mm, text height 235mm, top and side margins
27mm;
\item A serif font such as the standard \LaTeX{} font or ``Times'' and a font size
of 12pt;
\item Page numbers should be included, centered at the bottom of each page
\item References like \cite{ex} and (sub)sections should be numbered like in this sample.
\end{itemize}
Camera-ready papers that do not meet these specifications will not be accepted.
