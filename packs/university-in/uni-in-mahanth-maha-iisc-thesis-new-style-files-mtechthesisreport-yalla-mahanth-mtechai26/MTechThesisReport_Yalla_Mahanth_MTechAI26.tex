\chapter{Introduction}

\section{Purpose of this Demo}

This file demonstrates \texttt{iisc\_thesis\_new.sty}, the \LaTeXe{}
modernisation of the original IISc thesis style.  Every layout rule from
the 1991 original is preserved, while adding support for all modern packages.
The citation system now uses BibTeX with a \texttt{.bib} file
\cite{MtechAIatIISc2026}.

\section{New Features}

\begin{itemize}
  \item Full \LaTeXe{} compatibility -- \verb|\usepackage| works everywhere.
  \item Math via \textsf{amsmath} / \textsf{amssymb}: $E = mc^2$,
        $\int_0^\infty e^{-x}\,dx = 1$.
  \item Graphics via \textsf{graphicx} (Chapter~\ref{ch:elements}).
  \item Better tables via \textsf{booktabs} (Chapter~\ref{ch:elements}).
  \item Clickable cross-references and PDF bookmarks via \textsf{hyperref}.
  \item New \verb|\mtech{<discipline>}| degree command.
  \item Logo loaded with \verb|\includegraphics| from \texttt{iisclogo.jpg}.
\end{itemize}

\chapter{The \texttt{\textbackslash mtech} Command}

The \verb|\mtech| command sets the degree to ``Master of Technology''
and prints the discipline on the title page.  Its syntax is:

\begin{lstlisting}[language=TeX, caption={Using \textbackslash mtech}]
\mtech{Artificial Intelligence}
\end{lstlisting}

This produces the following block on the title page:
\begin{center}
  \scshape Submitted For the Degree of \\[0.8ex]
  {\large\bfseries Master of Technology} \\[0.4ex]
  \scshape in \\[0.2ex]
  \normalfont Artificial Intelligence
\end{center}

All other degree commands from the original are still available:
\verb|\phd|, \verb|\mscengg|, and \verb|\me|.
