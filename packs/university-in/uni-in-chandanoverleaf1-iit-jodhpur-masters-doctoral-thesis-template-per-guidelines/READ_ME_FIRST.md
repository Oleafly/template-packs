# Doctoral-template-IITJ
Doctoral/Masters Thesis Template of IIT Jodhpur


1. Run the "LuaLaTex" compiler in main.tex (IF YOU ARE USING OVERLEAF, YOU CAN FIND IT BY CLICKING ON THE "MENU" OPTION ON THE TOP LEFT --> compiler (drop-down box) )

2. Edit the Title of the Thesis, Name of the Supervisor, Name of the Degree, Name of the Student, the Roll Number of the Student, and Name of the Department in main.tex.

3. The Chapters folder contains the .tex files of the thesis chapters and they can be compiled independently

4. Other .tex files are not independent run Thesis.tex to compile the changes made.

5. Fonts are per the IIT Jodhpur doctoral thesis guidelines.

6. There might be some spelling errors; use cautiously !!
