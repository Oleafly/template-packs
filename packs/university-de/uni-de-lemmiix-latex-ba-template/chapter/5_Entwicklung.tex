\section{Entwicklung}\label{sec:development}
Wenn Code eingebettet werden soll, geht das mit der lstlisting Funktion:
\begin{lstlisting}
    // Netter Democode
	if (deadline.equals("isNear") {
		this.code();
	} else if (deadline.equals("tomorrow") {
		this.sweat();
	} else if (deadline.equals(inSomeHours.getText()) {
		this.hustle();
	} else {
		this.chill();
	}
\end{lstlisting}

Anstatt wie in Abbildung \ref{sec:development} gezeigt als Codeblock, kann man Code auch inline (in der Zeile) z.B. \lstinline{this.hustle()} mit dem \enquote{lstinline}-tag einfügen.
