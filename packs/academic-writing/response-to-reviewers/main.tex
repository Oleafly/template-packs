\section*{Reviewer 1}
\reviewcomment{Comment 1. Observation times}{The methods do not explain how
observation times were chosen. Please clarify whether the same schedule was
used on each day.}
\textbf{Response.} We have added the observation schedule and explained that
all route points were visited in the same order on each study day. We also
report the time of each measurement in the accompanying data table.
\location{Methods, page 3, paragraph 2; supplementary Table S1.}

\reviewcomment{Comment 2. Interpretation}{The conclusion appears to imply
that adding shade would improve comfort, but comfort was not measured.}
\textbf{Response.} We agree that the study cannot establish this effect.
We have removed that claim. The conclusion now describes the observed shade
patterns and identifies direct comfort measurements as a next step.
\location{Discussion, page 6, final paragraph; Conclusion, page 7.}

\section*{Reviewer 2}
\reviewcomment{Comment 1. Uncertain observations}{How were observations
handled when a point was partly shaded?}
\textbf{Response.} We have expanded the coding rule for partial shade and
added a summary of observations marked as uncertain. The revised limitations
section explains how this uncertainty affects the comparison between points.
\location{Methods, page 3, paragraph 4; Limitations, page 6.}
