# 贡献指南

感谢你帮助改进这个吉林大学本科毕业论文 LaTeX 模板。

`README.md` 面向模板使用者，本文档面向希望反馈问题、补充说明或提交修改的贡献者。请尽量保持改动小而清晰，方便后续审查、测试和发布。

## 1. 适合贡献的内容

- 修复模板编译失败、路径错误、字体错误或编码问题。
- 修正封面、目录、摘要、参考文献等排版与学校要求的明显偏差。
- 改进 `README.md`、FAQ、示例内容和使用说明。
- 优化 GitHub Issue / PR 模板、变更记录和发布说明等维护材料。

## 2. 反馈问题

推荐使用仓库内的 GitHub Issue 模板：

- `Bug Report`：用于编译失败、样式异常、字体缺失、路径错误等问题。
- `Documentation Task`：用于 README、FAQ、示例和说明文档更新。

提交问题时，建议补充以下信息：

- 操作系统、TeX 发行版和编辑器。
- 使用的编译链，例如 `XeLaTeX -> BibTeX -> XeLaTeX x2`。
- 触发问题的文件、报错日志、截图或最小复现步骤。
- 如果是格式问题，请说明参考的学校要求或对应页面。

## 3. 提交 Pull Request

1. 请先确认已有 Issue 或在 PR 描述中说明修改动机。
2. 保持单个 PR 聚焦一个问题，避免把无关格式化和功能改动混在一起。
3. 修改模板行为、目录结构或使用方法时，请同步更新 `README.md`。
4. 面向使用者可见的变化，请同步更新 `CHANGELOG.md` 的 `[Unreleased]`。
5. 提交前请检查 `git diff`，确认没有混入本地临时文件、编译产物或个人信息。

## 4. 提交前检查

至少完成以下检查：

- 使用推荐编译链完整编译一次模板。
- 确认 `main.pdf` 中目录、正文引用和参考文献编号正常。
- 确认新增图片、字体、PDF 或文档资产适合公开分发。
- 确认 `.aux`、`.log`、`.out`、`.toc`、`.synctex.gz`、临时压缩包等构建产物没有被提交。

## 5. 公开仓库注意事项

请不要提交以下内容：

- 带真实签字、学号、手机号、邮箱、身份证号等个人信息的材料。
- 仅适用于个人电脑的绝对路径、本地缓存或临时调试输出。
- 未确认再分发权限的字体、学校官方文档、校徽校名图片或扫描材料。

如果某个文件只适合本地使用，请优先在 README 中说明由使用者自行补充，而不是直接放入公开仓库。

## 6. 维护者参考

以下文件偏维护者视角，贡献者通常不需要修改：

- `PROJECT_MANAGEMENT.md`：项目目标、任务分层、里程碑与维护流程。
- `docs/GITHUB_SYNC.md`：仓库同步、冲突处理和远端维护说明。
- `CHANGELOG.md`：对外可见的版本变更记录。

正式发布时，维护者应先确认工作区干净、模板编译通过、`CHANGELOG.md` 已整理，再创建版本标签和 GitHub Release。
