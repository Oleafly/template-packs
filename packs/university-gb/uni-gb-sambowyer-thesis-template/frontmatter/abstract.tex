this was based on this template \url{https://www.overleaf.com/latex/templates/university-of-bristol-thesis-template/kzqrfvyxxcdm}

But I (read: Claude) have made a few changes:
\begin{itemize}
    \item lots of latex package imports (many of which you might want to remove, like \texttt{minted} for code-blocks)
    \item made links and chapter names University-red 
    \item Added an automatic word count to the title page, saved in \texttt{frontmatter/wordcount.tex} which you might need to update if you change the text by running \texttt{bash wordcount.sh} (you'll want to update this script to match your chapter structure)
    \item added 'Parts' (a level of hierarchy above chapters)
    \item added optional epigraphs to the parts/chapters
    \item Set up \texttt{cleverref} for cross-referencing e.g.:
    \begin{itemize}
    \item \verb|\cref{chap:clt}| gives \cref{chap:clt}
    \item \verb|\cref{clt:sec:clt}| gives \cref{clt:sec:clt}
    \item \verb|\cref{app:clt_app:sec:appendix}| gives \cref{app:clt_app:sec:appendix}.
    \end{itemize}
    \item Other small visual tweaks
\end{itemize}

This should align with the University of Bristol's PhD thesis guidelines as of August 2026:
\url{https://www.bristol.ac.uk/academic-quality/pg/code-of-practice/assessment/content-format/}

\end{SingleSpace}
