### Bibliography style: `uomagu.bst`

The bundled `uomagu.bst` is an AGU-like BibTeX style file derived from the custom-bib system. The file header states that it was generated from master bibliography style files including `merlin.mbs`, `physjour.mbs`, `geojour.mbs`, and `photjour.mbs`, and that the generated file may be redistributed and/or modified under the LaTeX Project Public License.

Original copyright notice in `uomagu.bst`:

> Copyright 1994--2004 Patrick W. Daly

The local filename `uomagu.bst` is used to distinguish this bundled copy from upstream AGU/custom-bib files.

### LaTeX packages

The class loads or expects packages commonly available in TeX Live/Overleaf, including but not limited to: `geometry`, `setspace`, `ragged2e`, `graphicx`, `amsmath`, `amssymb`, `booktabs`, `array`, `longtable`, `pdflscape`, `etoolbox`, `natbib`, `hyperref`, `bookmark`, `fontspec`, `unicode-math`, and `hyphenat`.

These packages are not bundled here and remain under their respective upstream licenses.

### Fonts

The class uses Times-compatible and math fonts available in TeX Live/Overleaf, such as TeX Gyre Termes X and STIX Two Math when compiled with LuaLaTeX. Font files are not bundled in this repository.
