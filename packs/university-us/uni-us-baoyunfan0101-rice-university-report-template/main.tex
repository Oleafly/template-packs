\section{How to Use This Template}

Most users should spend nearly all of their time editing this file: first the metadata block near the top, then the body sections below. The formatting logic is isolated in \texttt{format.tex}, so style changes can be made there only when needed.

\subsection{Recommended workflow}
\begin{enumerate}[leftmargin=1.5em,label=\arabic*.]
    \item Edit the metadata block in \texttt{main.tex}.
    \item Replace sample text section by section.
    \item Keep \texttt{format.tex} unchanged unless you want to alter layout, typography, colors, headers, or code style.
    \item Update entries in \texttt{references.bib} as needed.
    \item Compile twice so that references and the table of contents resolve correctly.
\end{enumerate}

\section{Purpose and Scope}

This template is designed to be reusable across different types of report writing. It keeps the formatting system in one supporting file while leaving the main document easy to edit.

\subsection{Example objectives}
\begin{itemize}[leftmargin=1.5em]
    \item Provide a clean cover page with structured metadata.
    \item Keep the body pages visually distinct with the owl image in the running header.
    \item Demonstrate how to cite a website source and a standard article source~\cite{ricebrandresources,samplemethod2024}.
    \item Offer sample structures that can be deleted or expanded with minimal effort.
\end{itemize}

\subsection{Sample equation}
A lightweight technical report may still need a compact mathematical definition. One example is shown in \cref{eq:weighted-score}.

\begin{equation}
\label{eq:weighted-score}
S = \alpha A + \beta F - \gamma T,
\end{equation}
where $A$ is accuracy, $F$ is the F1 score, $T$ is normalized runtime, and $\alpha$, $\beta$, and $\gamma$ are user-selected weights.

\section{Sample Code Block}

Many reports need a short implementation excerpt, experiment configuration, or analysis script. \Cref{lst:python-example} demonstrates a compact code listing style.

\begin{lstlisting}[caption={Sample Python snippet for data aggregation.},label={lst:python-example}]
def weighted_score(accuracy: float, f1: float, runtime: float,
                   alpha: float = 0.5, beta: float = 0.4, gamma: float = 0.1) -> float:
    """Compute a simple demonstration score for template examples."""
    return alpha * accuracy + beta * f1 - gamma * runtime

sample_rows = [
    {"name": "baseline", "accuracy": 0.81, "f1": 0.78, "runtime": 0.42},
    {"name": "revised", "accuracy": 0.86, "f1": 0.84, "runtime": 0.39},
]

best_row = max(sample_rows, key=lambda row: weighted_score(
    row["accuracy"], row["f1"], row["runtime"]
))
print(best_row)
\end{lstlisting}
